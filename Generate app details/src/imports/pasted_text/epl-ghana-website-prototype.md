# EMERGING PUBLIC LEADERS OF GHANA

## WEBSITE REDESIGN — FIGMA MAKE MASTER PROMPT

Create a **high-fidelity, fully responsive and interactive website prototype for Emerging Public Leaders of Ghana (EPL Ghana)**.

The website must be designed for:

* Desktop/laptop
* Tablet
* Mobile phone

This should be a **functional multi-page prototype**, not a collection of static mock-ups.

All major navigation items, buttons, cards, profiles, project sections, CTAs, forms and menus should connect to the appropriate page or section.

---

# 52. FINAL DESIGN PRINCIPLE

The website should NOT feel like:

"Here are six cards. Here are three cards. Here are four cards."

Instead, it should feel like a **story unfolding as the user scrolls**.

Use:

**Large image → statement → people → movement → project → evidence → story → invitation**

Create visual pauses.

Create moments of surprise.

Use animation to guide attention.

Use typography to establish authority.

Use photography to establish humanity.

Use statistics to establish credibility.

Use stories to establish emotional connection.

Use clear CTAs to establish action.

---

# 53. FINAL WEBSITE EXPERIENCE

The visitor should leave the homepage understanding:

**EPL develops people.**

**Those people serve institutions.**

**Those institutions affect Ghana.**

**And the visitor can become part of that work.**

The website should therefore feel:

**Human. Bold. Credible. Interactive. Optimistic. Ghanaian.**

Build the complete responsive prototype with this philosophy.

Do not produce only static screens.

Create the pages, states, interactions, responsive layouts, transitions and navigation necessary to demonstrate the complete future EPL Ghana website.
